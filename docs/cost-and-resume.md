# 处理量估算、用量记录与恢复

网页在资料读取后显示页或文字段数；真实章节计划产生后补充章节与处理单元，独立抽样计划产生后补充样本数。一个处理单元最多涉及 8 个原页，但章节仍按原资料组织。未规划的单元数和抽样上界显示“待确定”，不按科目或文件大小猜测。

调用范围按当前流程计数：逐页来源清单 P 次、规划 1 次、生成 U～3U 次、逐单元核查 U～3U 次、全局核查 1 次、抽样先读和对读各 S 次、实际截图视觉核查 1 次。无缓存时，成功回复总范围为 P+2U+2S+3 到 P+6U+2S+3；网络层每个逻辑请求最多尝试三次。来源不清、审校失败或额度不足仍可能提前停止，范围不是完成保证。

页面同时呈现实际已用次数、剩余额度和本阶段剩余流程的估算。已完成阶段从需求中排除，已消耗次数仍从总限额扣除；失败重试不会消失，读取已有缓存不增加网络调用。阶段内尚未完成的工作采用保守范围，不凭章节文件已经存在就认定无需核查。

## tokens、时长与费用

缺少相应阶段的真实用量或使用者显式提供的样本时，tokens、用时和费用为“未知”，不会显示为 0。读取已有日志和估算本身都在本地执行，不连接模型服务。

默认不配置价格。管理员可以显式指定以下两个 JSON 文件路径：

- `PORTAL_ESTIMATION_CALIBRATION_FILE`：逐阶段校准对象；格式见固定 Skill 的 `references/cost-and-resume.md`。`kind:user-supplied` 表示管理员提供的条件，`kind:measured` 必须具有与当前服务商、模型和整个 Skill 摘要一致的 `identity`。
- `PORTAL_ESTIMATION_PRICES_FILE`：`currency`、`inputPerMillion`、`outputPerMillion`；金额按管理员提供的统一输入、输出单价计算，不自动查询价格，不猜税费、阶梯价或缓存折扣。

两个文件仅从服务器本地读取，最大各 2 MiB；文件摘要写入任务估算记录。网页不会收到文件路径、校准原文、完整日志或密钥。完整阶段样本和显式单价缺一时，费用保持未知；只有时长样本时可以显示条件用时，但仍没有金额。

当前任务产生的真实成功请求也可提供同一服务商、模型和 Skill 摘要下的阶段观察。只有已知的计量项进入样本，失败和本地缓存耗时不混入成功请求估计。样本的最小与最大值只是条件范围，不是统计置信区间，也不是完成倒计时；失败请求、退避等待、排队、提取、构建和浏览器检查不包含在成功请求用时内。

## 实际记录与旧任务

任务私有目录的 `model-usage.json` 使用 `formatVersion:2`。每条请求记录阶段、请求摘要、实际服务商与请求模型、Skill 摘要、尝试序号、耗时和服务商返回的计量字段；不保存提示词、原文、密钥或完整错误响应。缺失 tokens 为 null。已知 tokens 的小计会标为“只含已知部分”，不代表完整账单。

每次网络尝试前先持久化 `pending` 并消耗额度。返回后改为 `success` 或 `failed`；中断留下的 pending 继续计入额度，结果保持未确定。`cache-hit` 单独记录，不计网络次数。每个逻辑请求的 `attemptIndex` 从 1 开始；`networkSequence` 在本任务内递增。

旧日志的总调用数原样保留。旧成功记录缺少的模型身份、尝试序号或耗时保留 null，历史完整性标为 false；“总次数大于明细条数”的差额是未分类尝试，不能擅自判成失败。回复缓存存在但调用日志缺失时会要求核对，避免重置额度。自动化测试产生的替身日志不用于真实模型基线。

`work-estimate.json` 保存阶段估算、实际日志摘要与可追溯来源；任务 API 只给出经过筛选的数字、范围和状态，旧任务没有估算文件时正常隐藏面板。

## 恢复的实际边界

同一任务的模型回复缓存按完整请求键复用，包括流程修订、Skill 摘要、模型、阶段、指令、数据和原页图片摘要；百炼还包括服务商与业务空间。改变原页、资料用途、模型或 Skill 版本会使相关请求重新执行。只复用完整成功回复，不复用截断或无效结果。

复用回复仍需重新进行当前结构、来源和审校证据检查，不能把已有章节当成免审许可。本地提取、组装、构建与浏览器验证仍会执行。新建任务、主动删除或保留期清理后不保证旧缓存可用。

## 验证入口

`python -m unittest discover -s tests` 覆盖计量日志、旧记录迁移、额度保留、未知值、阶段扣除和公开字段过滤。

`node tests/estimation.e2e.cjs /检查输出目录` 启动仅本机可见的确定性界面测试服务，使用真实浏览器核对未知值、已用额度、显式条件金额、宽窄屏及加载后断网可读。该测试没有真实模型调用；`EXAMPLE` 金额仅为显示测试数据，不是实际价格或成本基线。浏览器可使用 `PLAYWRIGHT_MODULE` 与 `BROWSER_EXECUTABLE` 指定已有环境。
