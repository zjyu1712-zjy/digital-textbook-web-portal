# 1.1.0 跨平台更新与验证

版本：1.1.0；核对日期：2026-10-25。

本次把安装、执行目录与能力检查改为标准 Agent Skills 工作方式；保留共用内容结构、偏好与学习记录格式，不要求 Codex 或某个模型 API。五门课程原件与网页部署工程未改动。

## 修改与缺陷回归

- 新增多宿主安装/调用说明、外部工作区环境检查和精确清单 ZIP 打包。
- 实测发现非 UTF-8 系统默认编码会使中文 JSON 读取失败；先复现，再统一构建文件与 CLI 输出编码。
- 实测发现缺浏览器工具时虽然报告未验证，退出码却为成功；现未验证返回 2，失败返回 1，通过返回 0，依赖异常提前退出也保留未验证报告。
- 环境检查与浏览器检查统一从工作区和技能目录定位 Playwright，解决个人安装目录找不到工作区依赖的问题。
- 打包器在 ASCII 终端遇到中文/emoji 输出路径时，曾生成成功却因输出编码报错；已用失败回归修复。
- 不再在没有截图时写“截图已提供”。环境探测与安装成功不代表语义或浏览器验证通过。

所有资料均为已公开的自编小样本，不是对完整教材、所有学科或所有模型的质量背书。详细运行报告和截图只保留在本次开发工作区，未把本机路径与真实教材打进发行包。测试执行前发现问题均先用失败用例复现，再最小修复；无未解决的本次回归失败。

发布包中不包含生产 API 配置，也无需增加收费模型调用。skills.sh 使用原 GitHub 来源；网页索引刷新时间不由本仓库保证。
