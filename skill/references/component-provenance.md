# 组件来源、维护与边界

Python标准库构建器及原生HTML/JS组件在本技能开发中实现。存储模块基于用户已有宏观课程项目的事务、不可改写提交、图片哈希和备份冲突方案提取并泛化；移除了原课程命名空间、题库和私人路径，新增跨教材预检及快照校验。数学资源沿用用户已有线代项目中的本地KaTeX发行文件，许可证见assets/vendor/KaTeX-LICENSE.txt；WOFF2是离线排版所需字体，不是依赖缓存。

测试fixtures/general-source.txt为本次自编的极小教材源。components为明确标记的合成输入组件，不代表某本教材的原题。五门真实课程、整本教材、真实作答数据和私有来源报告不属于这个技能包。

维护偏好改references/preferences.md；资料优先级改material-modes.md；学科规则按discipline文件更新。修改内容格式须同步pipeline验证与schema说明；修改存储须用旧备份和旧快照做迁移测试，不换bookID规避兼容。未知旧HTML数据库没有通用自动迁移保证，须保留原件并为其真实格式建立适配与恢复测试。

已提供四种资料模式、六类可组合策略、九类输入，通用模式不等于任意学科专业答案已验证。资料提取与理解仍由调用模型执行，脚本只自动化盘点、结构/引用/公式/资源校验和打包；OCR缺页或歧义须回看原页并明确报告。完整性始终依赖独立来源清单与有范围的语义核查。
