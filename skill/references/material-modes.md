# 资料组织模式

|模式|主线与覆盖|辅助资料|
|---|---|---|
|textbook 教材主导|实际教材目录及本次范围；仅一本教材时默认|解析配题，辅导总结独立；不替代正文|
|slides 教师课件主导|用户指定的真正上课PPT，逐页实质内容|教材解释和推导，精简版不能替换主课件|
|outline 提纲主导|提纲所有条目/分点/提示；教材完整展开|教材其他重要内容另列补充，真题不能决定删减|
|combined 组合资料|根据用户要求指定多个资料的主次与对应|逐来源保留冲突、版本及题目自身条件|

实际读封面、页内标志、目录、正文判断角色，不仅依据文件名、白底外观或名为“答案”。书名、作者、版次、册别、卷别、年份、学期缺失则明确未标明。资料角色存在真正重要歧义才提问。

优先级：用户本次/后续明确要求→该任务指定主资料→与题干版本和数据匹配的解析→其他辅助资料→明确标出的AI补充。原题数据即使与课堂简化假设不同也保留；不要静默合并版本。

分批资料等待规则来自当次用户要求，不把所有单本教材转换都变成等待。资料只含节选时，scope.completeness=excerpt 并显示范围。目录列出的缺页章节登记在 issues，不生成虚构正文。没有真题时显示“未提供”，不生成往年卷。

## 资料融合的共同要求

四种模式都先按用户目标、指定的资料主次及用途组织内容，不因文件类型自动决定主导资料。同一项目已确认的约定继续沿用；其他课程或任务重新依据其要求判断。若资料用途或主次存在会改变学习主线的重要歧义，再向用户确认。使用任务指定或实际提供的教材版次，不固定为某本书、某一版或某个章节范围。

1. **读内容再融合。** 对用户要求纳入学习的教材、PPT、提纲、解析、真题等逐项提取实质内容，按约定学习主线放入对应知识点或题目。将互补的定义、条件、机制、推导、图表、例证及解题方法整理成连贯讲解，合并重复内容并保留来源；不能只附上文件、提取文字或整页图片。用户明确只作存档或原页对照的资料按该用途保留，不擅自改作主讲内容。
2. **总结与重点同步体现融合。** 导读、知识点讲解、重点辨析和章末总结须反映各资料按约定提供的信息及其联系，不能正文未吸收新增资料却仅标“已收录”。重点依据用户要求、主资料的实际展开及明确复习安排，记录相应定位，不推测未提供的考点、分值或考试权重。解析和真题可用于对应方法、条件和易错点，不能反过来决定删减约定范围内的知识。
3. **核查实际讲解。** 将原资料实质条目及其条件、公式、图表、例题映射到相应讲解或题目；封面、目录、过渡和结束页注明用途。检查时对读原资料与成品，确认知识得到解释、总结及重点符合约定。仅链接原页、页数相等或非空映射均不证明融合完成，不强制一页对应一个主题。
4. **完整保留，分层阅读。** 章首区分主要学习路径、复习与对照资料；完整原文、原页和来源按需展开或分组进入，避免全部挤成同级入口。约定范围内未进入主要学习路径的实质内容仍作为补充保留，原题与小问不删减，旧链接继续可达。

主次决定教学顺序和侧重，不决定事实真伪。资料的定义口径、模型条件或数据有冲突时，保留各方定位，解释适用条件；可确认的错误另列校核说明，无法确认的明确待核对，不因某份资料优先而照抄错误。

## 课件主导的逐章融合

仅在本次任务明确采用 slides 模式时，以实际授课PPT安排知识顺序与讲解侧重，用教材补定义、适用条件、机制、推导和例证；导读与章末总结采用同一课堂主线。逐页阅读并按上述共同要求实质融合，不能只把PPT附在仍不符合约定的教材主线后。

若已约定课件主导、后续还会补课件，但目前仅部分章节有PPT，在 `organization.reason` 和相应章节注明现有资料与待补范围；尚无PPT的章节保留完整教材及待补入口，不虚构课堂重点，也不将整书误标为已完成课件融合。缺少尚未提供的辅料不等于教材缺页；用户要求等齐再开始时仍应等待。教材或提纲主导的任务，新增PPT按其辅助用途融入，不自动改成 slides 模式。具体增量处理见 [转换与检查点](workflow.md)。
