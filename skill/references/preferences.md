# 个人学习偏好（可独立维护）

这些是用户明确标准，不是从旧成品的数量推测出的上限。证据来源为本次开发请求 U0、五课程对话中可访问的用户要求，以及2026-11-11关于按使用者要求实质融合资料的明确修订。单一课程的资料主次保留在该项目，不作为所有课程的默认。私有路径与原文不打包。

- P01 约定范围内的原资料和实质讲解须完整保留，辅导书摘要不替代正文；不要用卡片数量限制教材。完整性不等于教材永远占据学习主线，呈现主次按P07执行。依据 U0、线代初始要求、统计学后续修订及资料融合修订。
- P02 同一 HTML 内首页、独立章节、原例题/习题、真题整卷入口、历史；章内导航、搜索、题目往返保留草稿。依据 U0、五课程学习系统要求。
- P03 不按“已学/未学”“前六章/后续”降低章节完整性。用户已约定后续补资料时保留现有完整内容并注明待补，补入后按本任务约定融合；不能虚构尚未提供的内容。依据统计学后续明确否定及资料融合修订；课程特定排除范围另按当次约定。
- P04 解析默认隐藏，原题按原型作答，主观题参考对照/自评。依据 U0、会计/线代/马原/宏观要求。
- P05 每次提交追加；保留草稿、附件、版本和看答案状态；可完整备份。依据 U0、五课程要求。
- P06 单文件、完全离线、直接打开；不要求安装、服务器、账号/API。依据 U0，覆盖宏观早期多文件入口设计。
- P07 资料主次和用途按具体任务及使用者要求确定，不绑定课程名或文件类型，不将某一课程的PPT主导约定推广到其他课程。凡要求纳入学习的资料，都须按约定实质融入知识点讲解、总结和重点呈现，不能只是附加文件或原页；明确仅作对照、存档的资料按其指定用途处理。教材主导、课件主导、提纲主导及组合资料均执行 [资料融合的共同要求](material-modes.md#资料融合的共同要求)。依据2026-11-11用户明确澄清。
- P08 只根据实际资料制作；缺页节选、官方/非官方答案、冲突必须可见。依据 U0及五课程要求。
- P09 平静清晰的阅读界面，长正文分节，来源与长解析按需展开；章首区分主要学习路径、复习与对照资料，避免同级按钮堆叠。当前默认纸色/深绿为可替换风格，不冒充用户唯一偏好。

修改配色只需改 `assets/style.css`；安装目录只读时，先将技能完整复制到该次工作区，修改副本并使用副本的构建器，不改共享安装。`build --assets` 指教材图片目录，不是模板覆盖选项。修改资料默认主次只需调整本次任务偏好或工作副本中的此文件/资料模式；不得因此修改稳定教材 ID、存储键、题目 ID 或清空历史。用户下一次明确要求优先于此文件。
