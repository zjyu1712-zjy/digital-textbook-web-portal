# 个人学习偏好（可独立维护）

这些是用户明确标准，不是从旧成品的数量推测出的上限。证据来源为本次开发请求 U0，以及五课程对话中可访问的用户要求。私有路径与原文不打包。

- P01 完整正文优先，辅导书总结仅作辅助；不要用卡片数量限制教材。依据 U0、线代初始要求、统计学后续修订。
- P02 同一 HTML 内首页、独立章节、原例题/习题、真题整卷入口、历史；章内导航、搜索、题目往返保留草稿。依据 U0、五课程学习系统要求。
- P03 不按“已学/未学”“前六章/后续”给章节不同待遇。依据统计学后续明确否定；课程特定排除范围另按当次约定。
- P04 解析默认隐藏，原题按原型作答，主观题参考对照/自评。依据 U0、会计/线代/马原/宏观要求。
- P05 每次提交追加；保留草稿、附件、版本和看答案状态；可完整备份。依据 U0、五课程要求。
- P06 单文件、完全离线、直接打开；不要求安装、服务器、账号/API。依据 U0，覆盖宏观早期多文件入口设计。
- P07 资料主次由任务决定：会计节选教材、线代教材、马原提纲加教材、宏观教师主课件、统计教材。不是永远绑定课程名。
- P08 只根据实际资料制作；缺页节选、官方/非官方答案、冲突必须可见。依据 U0及五课程要求。
- P09 平静清晰的阅读界面，长正文分节，来源与长解析按需展开。当前默认纸色/深绿为可替换风格，不冒充用户唯一偏好。

修改配色只改 `assets/style.css`；修改资料默认主次只改此文件/资料模式；不得因此修改稳定教材 ID、存储键、题目 ID 或清空历史。用户下一次明确要求优先于此文件。
