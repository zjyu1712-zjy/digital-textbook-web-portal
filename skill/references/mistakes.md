# 错题本与复习记录

错题本从已有提交和用户标记生成，不复制、覆盖或删除原提交。入口在学习导航、题目页和学习历史中。

## 收录与撤销

- 自动收录需要保存的判分明确为错误，判分类型为数值或选择题，且按当时题目、参考答案和用户输入重新执行当前支持的精确规则后仍为错误。
- 旧记录只有文字“与参考规则不一致”或“不正确”时，也必须通过上述核验；数值精度丢失、无效规则、输入格式有误或已经无法确认的旧判分不会直接收录。历史页会提示用户对照后自行标记，原判分记录保持原样。
- 主观题、未完成草稿和“需重学”等自评不自动转换为错题。用户可在任意已保存提交旁选择“手动标为错题”。
- 取消手动标记仅撤销该手动来源；同一次作答若仍符合自动收录条件，会保留在错题本。

## 版本与复习状态

归集键是历史题目 ID、题目版本、答案版本及完整题目/答案快照的 SHA-256。即使版本号未变，只要快照内容发生变化，也会分成不同条目。每个条目展示同一快照下的历次作答，包含正确重做和原图片。

默认“待复习”；“已掌握”由用户明确设置，并记录当时的错题证据集合。后续出现新的错答或新的手动错题标记会恢复“待复习”。正确重做不会删除旧错误，也不会替用户自动宣布掌握。

打开当前题目时优先检查当前 ID，找不到才沿 `migrations.questionAliases` 逐项查找，并防止循环。当前版本改变、ID 迁移和已删除的题目分别显示说明；没有可用目标时只保留快照查看及导出，不提供失效的作答链接。旧版章节仍可作为独立筛选项。

## 存储与导出

沿用 IndexedDB 结构版本 1 与完整备份格式 1，新增信息均写入原有 `events` 表：

```json
{"type":"mistake-mark","attemptId":"已保存的提交ID","marked":true}
{"type":"mistake-review","groupKey":"64位快照摘要","state":"mastered","evidenceIds":["auto:提交ID","manual:标记事件ID"]}
```

每次操作追加唯一事件，带 `courseId`、`id` 和时间；不得覆盖旧事件。同一标记或条目的连续操作按事务顺序保持时间递增，避免同一毫秒的撤销被反向解释。`mastered` 之外的复习状态为 `review`。完整备份导入会验证事件字段，并拒绝没有对应提交的错题标记。不同浏览器/设备产生的同时间事件以时间及事件 ID 确定顺序；需要改状态时可在恢复后重新设置。

“导出当前筛选的错题”生成 `digital-textbook-mistakes` 格式的 JSON，包含筛选条件、归集条目、关联提交、图片和事件。它便于保存或进一步整理，不是完整备份，不接受作为完整备份导入。跨浏览器恢复须使用“备份与恢复”的完整备份，错题与复习状态会一并恢复。

写入失败时不显示标记成功，不改变已保存状态；进入只读模式后仍可查看已有错题并导出。浏览器支持 BroadcastChannel 时，同一存储入口的其他页面会更新错题本和历史视图；不支持时重新打开入口即可读取最新保存内容。

## 验证

- `node tests/mistakes.cjs`：客观规则、旧判分精度、显式标记、状态证据、改版分组及 ID 迁移。
- `node tests/mistakes-ui.cjs 自写示例.html 输出报告目录`：用独立浏览器数据目录真实作答，验证图片、筛选、双页同步、下载、完整备份恢复、改版/删题及写入失败；宽屏和 390 像素截图另作人工检查。使用 `examples/demo-course.json` 构建的自写示例，不使用个人学习数据。
